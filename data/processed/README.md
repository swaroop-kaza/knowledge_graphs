# Processed Data Workspace

This directory is intentionally reserved for generated local outputs.

Typical generated files:

- Smoke-test property graph, RDF, evidence graph, and Cypher exports.
- Technique benchmark Markdown and JSON reports.
- Candidate graph outputs written by the benchmark CLI.
- Dead-letter queues or local graph-store workspaces used during ingestion tests.

These files are reproducible from the source code, examples, and configs, so they are not kept as canonical repo artifacts.

# Code of Conduct

This project is for serious technical learning and implementation work. Contributors are expected to be respectful, constructive, and precise.

## Expected behavior

- Be kind and direct.
- Critique ideas and code, not people.
- Assume good intent, but ask for clarification when something is unclear.
- Keep discussions technical, inclusive, and useful to future readers.
- Respect privacy and do not post secrets, private data, or proprietary datasets.

## Unacceptable behavior

- Harassment, personal attacks, or discriminatory language.
- Publishing private information without permission.
- Repeated low-effort disruption of issues, pull requests, or discussions.
- Submitting intentionally harmful code, hidden telemetry, credential leakage, or unsafe defaults.

## Reporting

Report concerns through the repository security contact listed in `SECURITY.md` or by opening a private security advisory when the repository is hosted on GitHub.

Maintainers may remove comments, close issues, or block accounts when behavior harms the project or its contributors.

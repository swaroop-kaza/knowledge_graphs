# Code of Conduct

[Contributing](CONTRIBUTING.md) · [Support](SUPPORT.md) · [Security](SECURITY.md)

This project welcomes technical learning, research, documentation, and implementation work. Contributors are expected to be respectful, constructive, inclusive, and precise.

## Scope

This policy applies to repository issues, pull requests, discussions, code review, project events, and private project-related communication. It also applies when someone represents the project in a public space.

## Expected behavior

- Be kind and direct.
- Critique ideas and code, not people.
- Assume good intent, but ask for clarification when something is unclear.
- Keep discussions technical, inclusive, and useful to future readers.
- Give actionable feedback and make room for contributors with different levels of experience.
- Respect privacy and do not post secrets, private data, or proprietary datasets.

## Unacceptable behavior

- Harassment, personal attacks, or discriminatory language.
- Publishing private information without permission.
- Repeated low-effort disruption of issues, pull requests, or discussions.
- Submitting intentionally harmful code, hidden telemetry, credential leakage, or unsafe defaults.

## Reporting

Use the route that matches the concern:

| Concern | Report through |
| --- | --- |
| Community conduct | A private maintainer contact or GitHub moderation channel |
| Security, privacy, or data exposure | The private process in [SECURITY.md](SECURITY.md) |
| Ordinary project help | The channels in [SUPPORT.md](SUPPORT.md) |

Include the relevant location, a concise description, and any context needed to understand the concern. Do not repost harmful content more broadly than necessary.

Maintainers may edit or remove comments, close issues, reject contributions, or restrict participation when behavior harms the project or its contributors. Reports should be handled consistently, privately where appropriate, and without retaliation.
